# Evaluación de las clases espejo del periodo

Una ficha por clase real. Esta es la parte **académica** del piloto: no mide la plataforma, mide si la
colaboración funcionó. Es la que un evaluador de residencia leerá con más atención.

---

## Ficha de clase

| Campo | Qué anotar |
| --- | --- |
| `Clase` | C01, C02… |
| `Fecha y duración` | Día y horas totales de la sesión |
| `Instituciones` | Las que participaron. **Pueden ser más de dos** |
| `Docentes` | Uno por institución, con su rol en la sesión |
| `Materia y tema` | Nombre de la asignatura y tema concreto |
| `Nivel educativo` | Licenciatura, posgrado… |
| `Estudiantes por institución` | Cuántos, sin nombres |
| `Modalidad` | Videoconferencia: herramienta usada |
| `Horas de colaboración` | Horas efectivas de trabajo conjunto, no de conexión |
| `Objetivos de aprendizaje` | Uno por línea, y si se cumplió: sí / parcial / no |
| `Producto esperado` | Lo que los estudiantes debían entregar |
| `Evidencias` | Qué quedó registrado en la plataforma y qué fuera de ella |
| `Incidencias técnicas` | Cortes, audio, permisos, y cuánto duró cada una |
| `Reflexión intercultural` | Una o dos frases de lo que surgió del intercambio entre países |
| `Valoración del docente` | Del 1 al 5, y por qué |

## Preguntas que conviene hacerse al cerrar cada clase

1. ¿La coordinación por la plataforma ahorró algo, o se hizo todo por correo y WhatsApp?
2. ¿Los estudiantes de ambas partes participaron por igual, o una institución llevó el peso?
3. ¿Qué se registró en la plataforma que sin ella se habría perdido?
4. ¿Qué se hizo fuera y debería haberse podido hacer dentro?
5. Si esta clase se repite el semestre que viene, ¿qué habría que cambiar?

De cada respuesta, una frase con cita si es posible.

## Aviso sobre datos de estudiantes

En esta ficha **no van nombres ni matrículas**. Solo recuentos. Si una lista real se cargó en la
plataforma durante la sesión, eso se anota como hecho («se cargó una lista real de 24 alumnos con
consentimiento»), pero los datos no salen del sistema ni se copian aquí.
